# 🎓 CampusMate – Student Academic Companion

CampusMate is a Flutter-based student academic companion designed to help students organize and manage their academic activities through a simple, clean, and user-friendly interface.

The application brings important academic information together in one place, making it easier for students to track attendance, manage courses, view assignments, and organize their daily schedules.

## ✨ Features

- **Student Login & Registration** – Create student accounts and log in using student credentials.
- **Personalized Dashboard** – View academic information, attendance overview, today's classes, and upcoming assignments.
- **Attendance Tracking** – Monitor overall attendance percentages and view subject-wise attendance history.
- **Course Management** – Explore enrolled courses and access course-related syllabus information.
- **Assignment Management** – View upcoming assignments and track their completion status.
- **Class Schedule** – View weekly class schedules and add custom academic events.
- **Focus Timer** – Use a built-in timer to organize focused study sessions.
- **Student Profile** – View student information and manage profile settings.
- **Dark Mode** – Switch between light and dark themes.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code or Android Studio
- Google Chrome

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/tadinadasanjana/campusmate-flutter-project.git
```

**2. Navigate to the project directory**

```bash
cd campusmate-flutter-project
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application in Chrome**

```bash
flutter run -d chrome
```
